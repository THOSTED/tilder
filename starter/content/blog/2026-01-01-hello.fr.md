## Nom

bonjour - le premier article {mono}

## Synopsis

Un article est un fichier dans `content/blog/`, sa date dans son nom. Le même fichier est une page web et, pour `curl`, du texte brut qui se lit bien dans un terminal.

```console
$ curl example.org/blog/2026-01-01-hello
```

## Description

Le générateur transforme chaque fichier Markdown en une page HTML et en une page texte de 75 colonnes pour les terminaux.
