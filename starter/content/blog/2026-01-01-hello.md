## Name

hello - the first post {mono}

## Synopsis

A post is a file in `content/blog/`, its date in its name. The same file is a web page and, for `curl`, plain text that reads well in a terminal.

```console
$ curl example.org/blog/2026-01-01-hello
```

## Description

Write in a small, strict Markdown: sections, entries, lists, tables, callouts, *italics*, **bold** and `code`.

1. Write a Markdown file in `content/`.
2. The builder renders it twice:
   - an HTML page, in your theme;
   - a 75-column text page, for terminals.
3. Every change is rebuilt within a second.

| Output | For | Width |
|:-------|:----|------:|
| page | browsers | free |
| text | `curl`, `man` | 75 |

> [!INFO]
> Callouts, tables, highlighted code, images: see `builder/docs/markdown.md`.

## Example

```python
def greet(name: str) -> str:
    """Say hello, the man-page way."""
    return f"hello, {name}"
```
